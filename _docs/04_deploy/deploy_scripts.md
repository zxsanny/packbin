# Deploy scripts

No `scripts/deploy.sh`. The publisher is `.github/workflows/publish.yml`, which runs on a `v*` tag after the called `test.yml` jobs pass and `publish-gate.sh` matches the golden bytes. `publish-registries.sh` is the entry point: `publish-build.sh` (with `publish-inside.sh`, `publish-embedded.sh`, `publish-sign.sh` and `publish-check.py`) builds and checks every artifact, then `publish-upload.sh` (with `publish-query.sh` and `publish-published.py`) uploads; `publish-lib.sh` holds the target table and the credentials. `PACKBIN_BUILD_ONLY=1` runs the build phase alone with no credential and no registry write; it still needs `python3` on the host, `gpg` for the Java bundle and `git` for the vcpkg and Arduino clones, and it marks its artifacts so the upload phase refuses them even after a failed run. A local script that uploads the same registries would be a second publisher.
