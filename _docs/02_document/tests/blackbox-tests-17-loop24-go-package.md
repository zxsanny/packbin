# Blackbox Tests 17: Loop 24 Go package, the seventh language (FT-X-83 to FT-X-112)

Part of the blackbox set; the index is [blackbox-tests.md](blackbox-tests.md). Loop 24 (`go-package`, AZ-2222; AZ-2440 to AZ-2451, 12 specs, 45 points) added `go/` (module `github.com/zxsanny/packbin/go`): a hand-written Go package with the bytes of the other six for every shared feature, a Go driver in the language-pair ring, a `go` service in the CI suite, the Go golden gate and the `go/vX.Y.Z` tag (ADR-004). Sources: `_docs/02_task_plans/go-package/` (`problem.md` G-1 to G-6, `acceptance_criteria.md` GO-1 to GO-16, `scenarios.md` S1 to S12 and the assessment rows D1 to D8), the specs in `_docs/02_tasks/done/` (AZ-2440 to AZ-2451), `_docs/03_implementation/batch_01_loop24_report.md`, `_docs/loops/loop24/{review24,assessment24}.md`, [ADR-004](../adr/004_go-ships-as-a-git-tag.md).

This file uses one table row per scenario instead of the block form of files 01 to 16 (30 scenarios would pass the 500-line cap): the columns carry what the blocks carry (what is checked, the evidence, the expected result, the trace). Go test names are the real function names in `go/*_test.go`; a name such as `TestAC1...` carries the AC number of its task spec, not the GO number. A subtest of a table test is named by its case id.

**Where it runs.** Go is not installed on the owner's Mac (G-2). Every Go run is `golang:1.27` in Docker: `docker compose -f docker-compose.test.yml run --rm go` runs `.github/workflows/run-suite.sh go` (`gofmt -l`, `go vet`, `go test -race -count=1 -v`, `TestAC7SpeedRoundTrips` a second time without `-race`, `FuzzUnpack` for 60 s with `-fuzzminimizetime=0`, the one-dependency check; it fails without `go/go.mod`). Result of that service after the review fixes: `go,go suite,120000,PASS` (race tests 29.8 s, speed 160 ms typed and 128 ms map without `-race`, fuzz 1.19 M execs in 60 s, 0 failures). The ring builds the Go driver with `.github/workflows/ring-go.sh` (host `go` on CI; on a Mac a host binary cross-built in `golang:${RING_GO}`).

**Status words.** Covered: a test or script ran green in loop 24. NOT RUN: written, not executed in loop 24. BLOCKED: cannot run before a decision or an event. The last three scenarios (FT-X-110 to FT-X-112) are the NOT RUN and BLOCKED items; nothing else in this file is claimed beyond the batch report, the review and the assessment.
