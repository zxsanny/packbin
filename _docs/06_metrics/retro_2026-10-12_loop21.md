## Lessons

- A budget turns into a memory ceiling of `maxSlots` times the per-slot cost, and the per-slot cost differs by package (the same 4.3 MB packet: TypeScript 1 072 MB, Python 548 MB). Removing the Python first-round surcharge (U1) raised its worst case from 90 MB to 548 MB; change any charge only with a measured worst-case memory A/B in the same loop.
- A parity decision names the constructs it covers: "refuse a short list in an optional flags position" was implemented for `repeat` and left `times` accepting it (README Times, AZ-2248), and the reference worker had to decide that alone. Put the construct list (`repeat`, `times`, split bit, combined `flags`) in the decision.
- "Probe, then align" needs the no-value variant in the probe list: the U7 probe found the with-value row consistent and the no-value row (`010000`) inconsistent with U6; ask for both rows in the decision batch.
- A construction rule that rejects a body "with no member" must say what a member is: the TypeScript reference had to keep a zero-width `bytes` as a member because older hostile vectors build it, and C++ checks only direct children; one sentence in the spec saves a parity row.
