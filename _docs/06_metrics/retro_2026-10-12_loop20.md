## Lessons

- The reference-table pattern worked a second time: TypeScript wrote 28 + 10 hex-pinned rows and exact messages before the other four started; four packages reproduced them and the review found no budget bypass in any of five. The differences that remained (slot width, Python's unpack surcharge, flag byte names, older message texts) were the accounting each package already had; the first draft of the table should list the per-package accounting probes so they are decided before wave 1b, not ruled afterwards.
- A bytes-and-slots budget bounds the output, not the work: an empty round body charges nothing and a 1.1 MB request bought 93 s of CPU in TypeScript (F33). A limit has to charge a unit for every unit of work, including the empty one.
- A fix to an unpack-side check can invert it: the C# round collection rule was written from the spec text (`List<int>` refused, `List<long>` builds) instead of from the unpack binding, so a buildable scheme was refused and an unbindable one accepted (A1, High). The construction check inside a round is now the binding predicate itself, tested as "built if and only if bound" over 23 member types.
- A timing assertion is the first thing to fail when a hot path gains code and the machine is busy: the budget added 13 to 20 % on the typed round trip (idle A/B in the same CI image, loop 19 commit against HEAD), two timing tests failed under load, and both passed idle. Take the A/B before arguing load or regression.
- A test that starts a child interpreter must give the child the parent's import path: the AC-1 memory test passed for the worker (editable install) and failed in the clean CI container (`ModuleNotFoundError`).
- Long unattended runs on this laptop: it sleeps, so monitor and `alarm` timers count wall time and fire early, a subagent output file is a symlink (`stat -L`), `setsid` does not exist on macOS, and a network drop kills subagents (`ENOTFOUND`) and large downloads (`unexpected EOF`).
