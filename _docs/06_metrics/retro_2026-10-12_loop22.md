## Lessons

- A stage timeout written as `perl alarm` counts wall time across laptop sleep, and the alarm survives `exec` into `docker compose`, which does not stop on it: stage 1 failed with rc 142 after a sleep and the ESP stage ran far past its limit. Before a total run check `uptime` and `sysctl vm.swapusage`; if the host is swapping, stop other Docker work first or defer the heavy stages (ring, publish gate, ESP) to a quiet hour.
- A lowered limit lowers peak memory by less than its ratio: a quarter of the slots gave 29 to 33 % of the old peak because the runtime and the packet stay. State the memory acceptance as absolute MB per package and give a measured bound 50 % slack.
- A hostile construct case whose scheme another rule refuses first passes for the wrong reason (the scope rule fired before the empty-body rule in five packages). Check which rule fires per package when a case is added, and pin it.
- Validation state stored on a user's node leaks between schemes: Python kept `count_source` on the shared leaf and the last scheme won; copy the node at bind, as a `times` already was.
- Probe the "other packages do X" premise of a parity spec before writing the AC: two of the five premises of loop 22 (U14, U15) were false or ambiguous and were caught by the reference probe section.
