## Lessons

1. **[architecture]** In a heap-free port, link the device image after the first nested kind and read flash and stack before writing the next one: this loop's on-the-fly reference lookups took the image from 2.6 KB to 11 KB against an 8 KB limit, found only at the end of the slice.
2. **[testing]** A differential layout list must place every container kind under every presence context (`flags` member, flag bit, `when` body): the review found a `repeat`-in-`flags` divergence that 27 layouts and 80,000 random rows did not reach.
3. **[estimation]** Before sizing a slice of a port, check that each of its kinds can be decided with the code already there: dictionaries were in the lists slice but their key order is compared on decoded text, which only the text slice brings.
