## Top Lessons

1. A differential over valid schemes cannot find a throw that needs a mismatched scheme: after rewriting a conversion path, probe it once with a hostile value outside the member's range (a u32 above `int.MaxValue` into a `List<int>`); one 7-byte packet found what 1.4 million random lines did not.
2. Before writing a speed-up into an acceptance criterion, measure the floor of the part the change keeps: the engine's dictionary pack and read costs 130 ms cold of the 570 ms, so "3x" was out of reach without a second walker, and the loop delivered 2.1x cold and 2.3x warm.
3. A timing assertion needs its own non-parallel test collection: the AC-10 test takes 340 to 390 ms alone and 790 ms to 1 s inside the full xunit suite on a fast laptop, and failed CI at 1 618 ms; a local pass on a fast machine is not CI parity for a timing assertion, so run it isolated and expect the slowest runner.
4. A worker that stalls before its first edit costs nothing but time: resume it with a smaller first step and a report checkpoint, and let the parent verify each stage (diff scope, file sizes, both targets) before the commit.

## Suggested rule or skill updates

- `autodev/protocols/parallel-subagents.md` and the worker prompt boilerplate: forbid every index write (`git add`, `git rm`, `git mv`, `git restore --staged`) next to stash, checkout, reset and clean.
- `test-run` perf mode: when a timing test sits in a parallel suite, report its isolated time and its time inside the suite.
