## Top 3 improvement actions

1. **Read the target's ownership model before estimating a port.** A "port package X's design" task is sized by the target's data model, not by the source's line count. The check before points are written: grep the target's public types for owned heap types (`Vec`, `String`, `HashMap`, `Rc`, `Box`) and note whether the requested property (no heap, no panic, no exceptions) is a switch or a second API.
2. **Prove "free of X" on a linked image, not on lints.** The lint deny list was clean while the image held three panic paths. Any no-heap, no-panic or no-exception claim gets a symbol check on the linked artifact with a seeded defect that must fail it.
3. **Loop lists are read on a spare file descriptor.** A `while read` over a list whose body runs docker, QEMU or cargo can lose the rest of the list to the child's stdin; the review found it before a second feature set existed.
