## Top Lessons

1. Run the workers' own suites per batch, then one total review and one total test run for the loop; per-batch reviews and Docker runs were most of the wall time.
2. Before asking the owner an all-packages question, check in each package that the rule is decidable and run a differential for who breaks (Java has no field names; Python names are accessor keys; the "no break" claim for element accessors was false).
3. Every pack-side rule needs an unpack-random-bytes then repack differential against HEAD: the Rust round-name regression was invisible to forward tests.
4. A subagent command must end on its own: stdin from `/dev/null`, a `timeout`, no leftovers; a stuck command looks like live work.
