## What went well

- The spec pass found the one design flaw (eager `times`) by running prototypes of all four packages against their existing suites and re-deriving every hex, count and expected value; no implementation round was spent on it.
- Four parallel workers on disjoint paths finished batch 1 in about 15 minutes of wall time; mutation proofs in every task show the new tests fail when the check is removed; the read-only container probe fails 7 of 7 without the override.
- A refused 1 MiB packet now costs 20 to 90 MiB in all four packages instead of 0.3 to 1.2 GB, measured by the workers and re-measured by the README writer and the auditor.
- The audit corrected a claim the parent had accepted (F10 "fixed") and found a symlink path in F13 that the specs did not mention; both were closed within the loop.

## What to change

- Check every README claim of a bound against all counted field types, not only the one fixed (the audit found `bits` and `packed` still at 36 to 257 times the packet after "memory is bounded").
- Do not run four Docker-heavy workers at once on this Mac; two per batch keeps `Nfr_RoundTripsWithinOneSecond` stable.
- Keep a worker out of git state: no stash, checkout or reset in the shared tree.
- Add the `tsc --noEmit --strict` job to `test.yml` (open since loop 11) and a test that derives the service list of the compose override from the base file.
