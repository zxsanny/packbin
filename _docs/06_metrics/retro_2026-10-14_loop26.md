## Lessons (also appended to `_docs/LESSONS.md`)

1. A toolchain image tag is a fact to verify against the registry before it is written into a pin, a compose file and a guard (`swift:6` did not exist; `docker pull` in step 11 found it).
2. A sanitizer or emulated run changes the cost of a test by 10 to 40 times: mark single-threaded size and speed tests to skip under it and assert time bounds only in the plain runs.
3. A test that depends on a platform library's hashing (Foundation on Linux) is flaky unless its precondition is asserted first.
4. Run the first container build early in a new-language loop (after the core task), not at step 11: the five Linux defects cost three step 11 invocations (about 90 minutes).
5. A security audit that measures (peak RSS, a quadratic probe) finds what review cannot: F47 was invisible in the code and cost 25 s a MiB.
