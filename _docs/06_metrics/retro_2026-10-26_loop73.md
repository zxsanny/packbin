## Top actions

1. Before writing or keeping a security or test mechanism, read the language's own documentation for its guarantee, and say in the spec which official mechanism is used (promoted to `AGENT_GOTCHAS.md`; second time after loop 72).
2. Before offering the owner "leave X, it only holds derived data" for a crypto temporary, check whether X can be inverted back to its input: the SHA-256 schedule window gives back the whole block (loop 73 review).
3. When a secret lives in an `Option`, wipe it in place and then set `None`; never `take()` it out, which can leave the bytes in the slot.
4. For a byte-budget change that touches several feature sets, compare the figures of each candidate form per set and in total against the tightest bound, not the first set measured.
