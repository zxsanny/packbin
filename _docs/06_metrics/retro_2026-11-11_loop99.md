## Quality

Found by running or differential testing, not by the unit tests:
1. The seeded unpack run found a writer bug (a flags byte or `f64` written exactly at a buffer growth threw `IndexError` out of `pack`).
2. The TypeScript parity tables found a `times` in an anchored group that packed a count without its round.
3. The hostile loader found two cases (`count_behind_clear_flag*`) where Dart answered a short packet and the file lists `bad_value`.
4. The total review (random schemes against TypeScript, about 520,000 cases) found one High that 1,887 tests had not: a Field object used in two places of one scheme overwrote slot numbers (identity-keyed maps at build time); and the audit found a Medium: a dictionary whose keys share one string hash costs 20 s per 2.8 MB (unseeded hash).
5. The review of the release scripts found a High that would have gone red in CI (`report-row.test.sh` did not list Dart) and a High in design (the pub.dev token minted before a build that outlasts its 5-minute life).
6. Step 11 found a wall-time assertion in my own new test (624 ms against 500 ms at host load 30), and Docker Desktop without outbound routes (restart fixed it).

Differential proof that held: text, ECC, frame and crypto matched TypeScript or OpenSSL on about 400,000 cases with no finding.

## Top 3 actions

1. A builder that keys maps by node identity must be tested with the same field object used twice (shared member lists); add that case to any new language's scheme tests. Random differential runs against the reference are worth one reviewer slice per loop.
2. Never assert elapsed time in a unit test that the loop runs at load: count the operation (keyed reads) instead; keep time bounds for the compiled speed program only.
3. Mint a short-lived credential in the step that uses it, and compare its lifetime with the order of the run (a token minted before a build phase expired before the upload); and treat a Docker `network is unreachable` as an environment fault: restart Docker Desktop, then rerun only the failed stages.
