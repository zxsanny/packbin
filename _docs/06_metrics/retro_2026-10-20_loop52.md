## Lessons

1. **[tooling]** A clippy-clean `no_std` module can still link a panic path (`split_at_mut`); only the link check on the device image sees it, so run the embedded stage after the first new kind of code.
2. **[testing]** Pair every "refused when the feature is off" test with the same scheme accepted when it is on: a wrong table size made a refusal test pass for the wrong reason.
3. **[process]** Under host load above 25 the publish gate fails on environment flakes; read the share's log, re-run alone, and run it below load 15.
