### 4. Pack with a count the row carries

`pack` writes as many rounds as the row's `times` count states, with no bound: a Rust map `times` over a `flags` round with a `u32` count of 10,000,000 and no list returned 10,000,005 bytes in 1.2 s at 577 MB resident (`walk/pack.rs:366-399`); TypeScript the same row 10,000,005 bytes in 1.4 s; Python 5,000,005 bytes in 7.2 s (`_pack.py:279`). The receiver's default limit refuses more than 65,535 rounds, so such a packet could not be read back by a default scheme. F21.
