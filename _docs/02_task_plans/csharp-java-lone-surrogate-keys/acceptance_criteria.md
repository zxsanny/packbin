## Criteria

- **CJ-1 C# refuses a collision.** Given a dictionary whose keys are the same once each unpaired surrogate is written as U+FFFD (`{"\ud800", "\udc00"}`, `{"�", "\ud800"}`, `{"a", "\ud800", "\udc00"}`, `{"\udc00\ud800", "��"}`), When packed in C#, Then an `ArgumentException` whose message is `<field name>: two keys are the same once an unpaired surrogate is written as U+FFFD` is thrown and no bytes are returned. Packed as before: 0 of 4.
- **CJ-2 C# is otherwise unchanged.** Given the dictionaries without a collision (`{"\ud800", "￿"}`, `{"a", "\ud800"}`, `{"?", "\ud800"}`, `{"\ud800"}`) and a text with a lone half, When packed, Then the bytes equal today's (`0102000410efbfbd010410efbfbf02`, `010200021061010410efbfbd02`, `01020002103f010410efbfbd02`, `0101000410efbfbd01`, `010410efbfbd`). Mismatched bytes: 0; every existing C# test passes.
- **CJ-3 Java refuses a collision.** Given the 4 dictionaries of CJ-1 and `{"?", "\ud800"}` is not one, When packed in Java, Then an `IllegalArgumentException` with the message `dict: two keys are the same once an unpaired surrogate is written as U+FFFD` is thrown and no bytes are returned (4 of 4 refused).
- **CJ-4 Java writes U+FFFD.** Given a text or a dictionary key with an unpaired surrogate (a lone high half, a lone low half, a reversed pair, `a` + lone half + `b`, in the bare, raw (`中文` prefix) and compact (`hello world ` prefix) forms), When packed in Java, Then the bytes equal TypeScript's (the 16 packets of `dart/test/collections/lone_surrogate_test.dart`), and the dictionaries `{"?", "\ud800"}` and `{"\ud800"}` give `01020002103f010410efbfbd02` and `0101000410efbfbd01`. A "?" key is no longer merged with a lone half. Packets Java writes with a `?` for a lone half: 0.
- **CJ-5 Never unreadable.** Given 20,000 seeded random dictionaries of 1 to 4 keys over the units a, U+D800, U+DBFF, U+DC00, U+DFFF, U+FFFD, `?` and a valid pair, When each is packed and the result unpacked by the same package, Then every packet pack returns unpacks to the keys written as U+FFFD, and every refusal is a real collision. Unreadable packets: 0 in C#, 0 in Java.
- **CJ-6 Same as TypeScript and Dart.** Given the 5,000 seeded dictionaries of the loop 101 differential run (`gen.ts` output) and the 7 cases of the loop 101 report, When packed by C#, Java, TypeScript and Dart, Then all four refuse the same dictionaries and write the same bytes for the others. Disagreements: 0 (the "?" key cases are in the 5,000 only if the generator holds "?"; the 7 cases are checked by name).
- **CJ-7 Docs.** The README, the loop 102 findings and the C# and Java component docs say that C# and Java refuse two keys that become one, and that Java writes U+FFFD for a lone surrogate; no document outside dated history (`_docs/loops/`, `_docs/06_metrics/`, `_docs/03_implementation/`) says they write an unreadable packet.
