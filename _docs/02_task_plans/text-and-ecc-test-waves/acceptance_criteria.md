# Feature acceptance criteria — text and ECC test waves (loop 46)

Outcomes only. Each id is the loop 46 id; `/decompose` maps it to its task AC. Project ACs exercised: compact strings CS-5, CS-10, CS-11, CS-18 (`compact-strings/acceptance_criteria.md`), message ECC EC-9 and EC-10 (`message-error-correction/acceptance_criteria.md`), hardening HD-1 and HD-2.

- **TW-1** (CS-S3). In each of C#, Java, Rust, Go and Swift, 8 concurrent workers each pack and unpack at least 200 different texts at once with the same built scheme. Every packed field equals the reference bytes of `fixtures/text/vectors.txt` when the text is a vector row, and every unpacked text equals its input. Mismatches: 0. Errors: 0. The test finishes in ≤ 1 second nominal (scaled by the package's load factor). Go runs it under `-race`.
- **TW-2** (CS-A5). Every one of the eight packages runs at least 3,000 random Unicode strings (capitals, emoji, other scripts, combining marks, the empty string) through pack then unpack in its suite on every run. Mismatches: 0. Python, C# and Swift gain this test; TypeScript (4,000), Java (20,000), Rust (3,000), Go (3,000) and C++ (20,000) keep theirs.
- **TW-3** (CS-A10). Every one of the eight packages runs at least 30,000 hostile text payloads (random bytes and damaged valid packets) through unpack in its suite on every run. No crash, no hang, no output above 6 bytes per payload byte plus 8. Python, C# and Swift gain this test; Go rises from 20,000 to 30,000; TypeScript (30,000), Java (60,000), Rust (30,000) and C++ (100,000) keep theirs.
- **TW-4** (CS-5, CS-10 text). `_docs/02_task_plans/compact-strings/acceptance_criteria.md` says 3,000 random strings (CS-5) and 30,000 hostile payloads (CS-10) per package in the suites, and names the larger run (100,000 each, the loop 35 and loop 41 probes under `fixtures/hostile/fuzz/`) as a manual probe before a decoder change. The 1 ms per 64 KiB bound stays written with its basis (loop 41 probe, not a suite test).
- **TW-5** (CS-D7). In each of Java, C#, Rust and C++, a text of 65,535 characters written in 200 rounds (the setup of the Python and TypeScript HD-2 test) is packed and unpacked in ≤ 1 second nominal (load-aware) and the unpacked rounds equal the input. If a package misses the bound, the walker of that package is fixed in this loop and the packed bytes of every `enc` row stay unchanged.
- **TW-6** (EC-D2). The session cross-language check packs one protected session payload (the position row, parity n = 4, the session seed and nonce of the unprotected `session` row) in each of the eight languages: all eight payloads are equal to each other and to the value computed from the reference codec `scripts/ecc/eccfmt.py`, and every language that reads the unprotected session payload today reads the protected one from every other language (the same `handoff <from> <to>` pairs, both directions). Mismatches: 0. Added CI time ≤ 15 seconds on the group of `language-pair.sh`.
- **TW-7** (CS-D3 rest). In `_docs/02_document/tests/blackbox-tests-02-strings-lists-dicts.md`, FT-D-01 to FT-D-04 and FT-H-02 hold the compact-format hex as the reference encoder `scripts/text/textfmt.py` gives it (no old-format hex remains in the file).
- **TW-8** (matrix size). `_docs/02_document/tests/traceability-matrix.md` is ≤ 500 lines, with the moved rows in a side file named in the matrix (as loop 26 did) and no row lost (the row count of the two files equals the count before).
- **TW-9** (CS-D9 rest). `scripts/text/size_report.py` writes the run date and the sha256 of the recipe files into the header of `_docs/02_task_plans/compact-strings/size_report.md`, so a rerun of the script reproduces the committed file except the date.
- **TW-10.** No file under `cpp/src`, `cpp/include` or `cpp/embedded` changes; the vectors, the ring and the golden packet are unchanged.
