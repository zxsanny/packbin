## Criteria

- **AL-1 Lone surrogate, text field.** For a text field in the raw form, the compact form and the bare form, with each of the four texts lone high `\uD800`, lone low `\uDC00`, reversed pair `\uDC00\uD800` and `a\uD800b`, Dart packs the same bytes as TypeScript (16 cases in the results report) and unpacks every one of those packets to the TypeScript text, with U+FFFD in place of each lone half. Mismatched bytes: 0. Pack errors for a lone surrogate: 0. The byte budget (`maxBytes`) counts each lone half as 3 bytes (U+FFFD), so a text at the limit packs and one byte over is refused with the same member named as TypeScript.
- **AL-2 Lone surrogate, dictionary key.** A dictionary whose key holds a lone surrogate packs the same bytes as TypeScript (the three key cases in the results report) and unpacks to the key with U+FFFD. Keys are put in ascending order of the UTF-8 bytes **after** the swap: `{"￿": 1, "\uD800": 2}` packs `0102000410efbfbd020410efbfbf01` and its own unpack accepts it; `{"\u{10000}": 1, "\uDC00": 2}` packs with `efbfbd` before `f0908080`. Packets Dart writes that its own unpack refuses: 0 for these inputs.
- **AL-3 Keys that collide after the swap.** Given a dictionary with two keys that are the same text once each lone half is written as U+FFFD (`\uD800` and `\uDC00`, or U+FFFD and `\uD800`), When packed, Then Dart throws a `PackbinException` of kind `packError` naming the dictionary (`field` null, `name` the dictionary), and writes no packet. (TypeScript writes `0102000410efbfbd010410efbfbd02` here and refuses it at unpack: owner decision, follow-up for TypeScript.)
- **AL-4 Too long for its parity, at pack.** For count parity n of 1, 4 and 32 (limits 253, 250, 222) and percentage parity p of 1, 10, 50 and 100 (limits 251, 230, 222, 222), a clear message at the limit packs and one byte over throws a `PackbinException` of kind `packError` (term `pack_error`, not `tooLong`) with `field` null and `name` empty, whose `reason` is TypeScript's `RangeError` message: `the packet would be 251 bytes, above the limit of 250 bytes for 4 parity bytes` (count) and `the packet would be 231 bytes, above the limit of 230 bytes for 10 percent parity` (percentage). When `maxBytes` and parity both apply, the `maxBytes` refusal wins, as in TypeScript. Unpack of more than 254 bytes stays kind `tooLong` with the length in `left` and the limit in `reason`. The shared rows `lim` and `limp` of `fixtures/ecc/` keep their word `too_long`; Dart's tests map a pack error to it as Go's do.
- **AL-5 Dictionary key order, at unpack.** A repeated key, an out-of-order key and a repeat after a gap (`a,a`, `b,a`, `a,b,a`, `a,a` with 2 extra bytes) unpack to a short-read value with `needed` 0 and `left` 0, naming the dictionary (`ErrorKind.short`, term `short_packet`); TypeScript's results are the same. A valid ascending dictionary (`a,b`, `""` then `a`, a fullwidth tilde then a supplementary character) still unpacks. `bad_value` for key order: 0.
- **AL-6 Zero rounds, map rows.** For a map scheme, `unpack` of a packet with 0 rounds of a `repeat` or a `times` gives no key for the names of the round, in the 15 cases of the results report (a, b and c1 to c13: top level, in an anchored group, in an unanchored group or `nested` row, under a `when`, under `flags` and a flag bit, as a list element, a `when` inside a group). A group or nested map that holds only such rounds stays in the result as `{}`. Packing the unpacked map again gives the packet it came from in 15 of 15 cases; the two packets that are not what pack writes (a set flag bit over 0 rounds, `01000309` and `01010309`, cases c7 and c8) repack with the bit cleared, as in TypeScript. Pack of a map with the round keys absent still gives count 0 as today. A typed scheme still gives `[]` for a zero-round list. Cases that already match (c7 to c10): no change.
- **AL-7 Empty nested row as a mark.** An empty `nested(name, [])` directly inside `flags` or a flag bit builds and behaves as the member-less `groupOf` and as TypeScript's empty group: `true` sets the bit and unpack gives `true` for a set bit; an absent value and `false` leave it clear; a value that is not a `bool` is refused naming the mark (the rule of `groupOf`, Go-1 and Go-4). Bytes equal TypeScript's: `{h: 9, g: true}` packs `010309`, `{h: 9}` and `{h: 9, g: false}` pack `010209`; `010309` unpacks to `{g: true, h: 9}` and `010209` to `{h: 9}`. A set bit with the next field missing (`0103`) is a short read naming `h` with `needed` 1.
- **AL-8 Empty nested row elsewhere.** An empty `nested` as a plain row member, under a `when`, inside a non-empty group, as a list element, or as a dict element is refused when the scheme is built, with TypeScript's words: `empty group g: allowed only directly inside flags or a flag bit; move it into flags` (a `schemeError` naming `g`). An empty `nestedRow` stays refused when the scheme is built. A `list` or `dict` of an empty nested row never reaches pack (no packet Dart writes that its unpack refuses: 0).
- **AL-9 Text refusals, at unpack.** Every text that unpack refuses (overlong `C0 80` and `E0 80 AF`, an encoded surrogate `ED A0 80`, a value above U+10FFFF `F4 90 80 80`, a sequence cut by its count `E2 82`, and the 29 refusing rows of `fixtures/text/vectors.txt`, which are its 32 `bad` rows less the 3 of kind `short`: 8 cap, 9 utf8, 3 mode, 2 varint, 2 pad, 2 esc, 1 raw, 1 code, 1 length) gives a short-read value with `needed` 0 and `left` equal to the bytes from the start of the field to the end of the buffer (4, 5, 5, 6 and 4 for the five hand-made cases; one more as a dictionary key), as TypeScript. A buffer that really ends inside the text still gives `short` with the bytes needed (`010410e2`: needed 4, left 2). The seven hostile cases (`invalid_utf8`, `invalid_utf8_dict_key`, five `dict_keys_*`) pass with their Dart rule texts changed in `hostile_rules.dart`. `bad_value` for a text refusal at unpack: 0.
- **AL-10 Regression and gates.** `dart format --set-exit-if-changed`, `dart analyze --fatal-infos` (0 issues) and `dart test` pass; the shared fixtures run in Dart with 0 changed: text 418 rows, crypto 27, frame 157, ECC 1,328 + 1,044, hostile 75 (0 not run); the 957 TypeScript parity rows pass; the language-pair, ECC and frame rings show 0 mismatches for nine languages; the seeded unpack run reports 0 failures; no source file of the touched ones grows past 500 lines (`quality-thresholds.md`). Every row of `parity_differences.md` that names a test names one that exists (`parity_doc_test.dart`). The README, `fixtures/hostile/README.md` and the five parity rows say what the code does after the change, and no document says Dart refuses a lone surrogate or reports `bad_value` for key order.
