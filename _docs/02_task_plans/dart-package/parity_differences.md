# Dart parity differences

Every row where the Dart package builds, packs or refuses differently from the TypeScript package (the behavior reference, A-1). A difference is a refusal or a row shape, never different bytes. Rows are added by the task that finds them; AZ-4144 reviews the list against the parity suite.

| row | TypeScript | Dart | reason | Dart test |
|-----|------------|------|--------|-----------|
| `eq(u64, -1)` (a negative literal as the value of a `u64` source) | refused: `the value must be a whole number from 0 to 18446744073709551615` | builds; the value is the 64-bit pattern of the `int`, so it equals 2^64 - 1 on the wire (`ff` x 8) and the `when` runs for that packet | A-3: a `u64` is a Dart `int`, so -1 and 2^64 - 1 are the same 64 bits and Dart cannot tell them apart; `eq(u64, 0xFFFFFFFFFFFFFFFF)` is the same field | `test/checks/eq_range_test.dart`: `eq(u64, -1) builds and matches 2^64 - 1 on the wire`, `the literal 2^64 - 1 is the same pattern as -1` |
| `eq(i64, 2^63)` and `eq(u64, 2^64)` as a number | refused (a JavaScript number past the range) | no such value: a Dart `int` is at most 2^63 - 1 and wraps nothing silently; `eq(u64, 1e20)` (a `double`) is refused as not a whole number | A-3 | `eq_range_test.dart`: `eq(u64, 100000000000000000000.0)` |
| `eq(u8, 5.0)` (a whole-number float) | builds; 5.0 is 5 | refused: `the value must be a whole number from 0 to 255` | Dart tells 5.0 from 5, as Go, Swift, Java, Python and Rust do (owner decision Go-2) | `eq_range_test.dart`: `eq(u8, 5.0)` |
| `eq(u8, 5n)` (a `bigint` value) | builds | refused: a `BigInt` is not an `int` | `Condition.value` holds an `int` or `true`; a `BigInt` would need a 64-bit conversion with no gain | `eq_range_test.dart`: `eq(u8, a BigInt)` |
| ninth member of one `flags` | `flags()` throws when it is called | `flags()` returns and `scheme()` throws (the refusal names the ninth member) | a Dart field is a plain value built before any scheme; the error is the scheme's, as in Go and Swift (`nine_flag_bits` accepts `scheme_error`) | `construction_refusals_test.dart`: `nine members of one flags`; `hostile_construct_test.dart`: `nine_flag_bits` |
| members of an anchored `group` in a map row | packed from the nested object when given and from the flat keys of the row when not; unpacked flat | a nested `Map<String, Object?>` under the group's name, both ways; a flat key that names a member of a group whose map is not given is refused, naming the member (owner decision Go-4, as Go and Swift); an unpacked group is always a map, `{}` for a group with no value read | A-1 with Go-4 | `group_rows_test.dart` (every row); `group_refusals_test.dart`: `a member given flat (Go-4)`, `a member given flat under flags (Go-4)` |
| group in a typed row | none (TypeScript has no typed rows) | the members of an anchored group are bound to the same row as the fields around it; a group with no member (a presence mark) binds a `bool` with `bind` | A-5: a typed row is one object, and the group shares the scope of the fields around it | `typed_groups_test.dart` |
| a group that is not a map, or a mark that is not a `bool`, under a `when` that is false | not checked | refused when the row is packed, whether or not the group is reached | Go-4: the whole row is read before the first byte is written (as Go and Swift) | `group_refusals_test.dart`: `a group under a false when is checked too` |
| spelling of `bool` | `bool` | `flagBool` (a top-level `bool` would shadow `dart:core`) | Dart | `test/core/flag_byte_test.dart` |
| spelling of the anchored `group` | `group(anchor, accessor, fields)` | `groupOf(anchor, name, members)` (`group` is the name of `package:test`'s function, which every test file of a package imports) | Dart | `test/checks/group_rows_test.dart` |
| the unanchored `group` (a flat group with ids that restart at 0) | `group(accessor, fields)` | not built in this task: Dart's nested-row group arrives with the collections (AZ-4138) | scope | none yet |
| spelling of the round and counted helpers | `repeat(anchor, fields)`, `times(anchor, countId, fields)`, `sized(id, acc, countId)`, `u2(id, acc, ...)`, `bits(id, acc, countId)`, `packed(width, id, acc, countId, bias)` | `repeat(anchor, members)`, `times(anchor, countId, members)`, `sized(id, name, countId)`, `u2([slot(id, name), ...])`, `bits(id, name, countId)`, `packed(width, id, name, countId, bias: 0)` | Dart: the name is a string (A-5), `u2` takes `slot(...)` members as Go and Swift do, `bias` is a named argument | `test/rounds/readme_rounds_test.dart` |
| `packed` width 3 or bias -2, `u2` with no slot, a `slot` outside a `u2` | `packed()` and `u2()` throw when called | the helper returns and `scheme()` throws a scheme error naming the field | as the ninth flag member: a Dart field is a plain value built before any scheme | `test/rounds/construction_test.dart`: `packed width 3 and bias -2 are refused...`, `a u2 with no slot...`, `a slot outside a u2 is refused` |
| a map round with zero rounds | `unpack` gives no key for the names of the round | `unpack` gives an empty list for every name the round holds (`[]`, never `null`), for a `repeat` and a `times` | DT-12 zero value rule: an empty list is a value with 0 items, and it packs again to the same bytes | `test/rounds/zero_and_short_test.dart`: `an empty list for a times name packs count 0...`, `a repeat with no rounds ...` |
| a typed round | none (no typed rows) | a `List<E>` of a row type `E` made by a factory closure: `repeat(...).bind<R, E>(create:, get:, set:)`; every member of the round is bound to `E`; a typed `times` refuses a count other than the number of rows, naming its first member; a `null` list is no round (as an empty one for a count of 0); zero rounds unpack to an empty list | A-5, as Go's `Nested`/typed `Times` and Swift's typed `.times` | `test/rounds/typed_rounds_test.dart` |
| a group inside a map round | its members are lists under their own names (`{mark: {v: [7, 8]}}`) | a list with one nested `Map<String, Object?>` per round under the group's name (`{mark: [{v: 7}, {v: 8}]}`); a lone map goes to every round when it holds no byte buffer | owner decision Go-4 for rounds, as Go and Swift | `map_rounds_test.dart`: `a group in a round takes one map a round`, `a group map given once` |
| `bits` and `packed` values | an array of numbers; unpack gives a `number[]` | pack takes any `List` of `int` (a `Uint8List` too); unpack gives a `Uint8List` | Dart: one compact list of 0..3 per field | `readme_rounds_test.dart` |
| a `Uint8List` for a name of a round | a `Uint8Array` is not an array, so it goes to every round (and `bytes`/`sized` names refuse it) | the same: a `Uint8List` is a byte run, never the list of rounds; a `Uint8List` for any name but `bytes`, `sized`, `bits` or `packed` is refused as a wrong type | Go and Swift rule, a Dart `Uint8List` is also a `List<int>` | `map_rounds_test.dart`: `a lone byte buffer in a round is refused` |
| a `u64` count above 2^63 - 1 | a `bigint` past 2^53 is no count: unreadable (`short`, needed 0, left = bytes left); pack refuses it | the same refusal for any count that is negative as an `int` (a `u64` above 2^63 - 1, or a negative signed count); a count between 2^53 and 2^63 - 1 is a real count and ends in a short read with the count as `needed` (as Go) | A-3: a `u64` is a Dart `int`; no wrap, no allocation | `counts_test.dart`: `a u64 count above 2^63 - 1 is refused, not wrapped`, `a u64 count of 2^62 ...` |
| the packet byte limit (`maxBytes`) | refuses, naming the member | refuses with a pack error that names no field (the limit is the default constant; AZ-4139 makes it a scheme setting and names the member) | scope: the `Writer` has no field at hand | `limits_test.dart`: `a packet past 16,777,216 bytes is refused` |
| round limit errors on unpack | a short-packet value with `needed` 0 (the hostile README's interim shape) | an `ErrorKind.tooMany` value with `needed` 0 and `left` the bytes left, naming the round's first member; the limits are the default constants (65,535 rounds, 1,048,576 slots) until AZ-4139 | the hostile README allows `too_many` | `limits_test.dart` |
