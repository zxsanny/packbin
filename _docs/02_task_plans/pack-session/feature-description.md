# Pack session

Callers who pack a field list can keep the clear bytes. Callers who hide those bytes on a connection load one 32-byte seed. The side that opens the connection produces 16 bytes once. The waiting side joins with those bytes. Later payloads are the same length as the clear pack. Each client connection has its own session. The README shows both the clear pack and the session.

Six packages implement it. None imports another. C# is the reference. The other five match its ciphertext. Archangel's socket stays out of this repository.
